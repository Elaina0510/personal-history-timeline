# T01 项目脚手架与配置

- **对应模块**: MOD-015（前半：配置与静态骨架）
- **依赖**: 无
- **可并行**: 是（与 T02 同时开）

## 目标
从零建立一个能 `npm run dev` / `npm run build` / `npm run test` 的 Vite + 原生 TypeScript 工程骨架，并铺好目录与配置。**本任务不写任何业务逻辑**。

## 允许改动的文件（touchlist，超出即视为越界）
```
package.json
vite.config.ts
tsconfig.json
vitest.config.ts
index.html
.gitignore
src/styles-placeholder.txt     # 仅为占位，T12 会接管样式
```
另需创建空目录（用 `.gitkeep`）：`src/core/`、`src/ui/`、`src/ui/parts/`、`src/ui/styles/`、`tests/`、`public/data/`

## 必须满足的配置
1. `vite.config.ts` 中 `base: './'`（REQ-023：子路径部署不能 404）。
2. `index.html` 内含两个空容器：`<div id="timeline-root"></div>`、`<div id="overlay-root"></div>`，以及 `<div id="filter-bar"></div>`、`<nav id="year-nav"></div>`。顺序无关，但 id 必须完全一致（§4.6 DOM 契约）。
3. `package.json` scripts：`dev`、`build`（`tsc --noEmit && vite build`）、`test`（`vitest run`）、`typecheck`（`tsc --noEmit`）。
4. 依赖只允许：`vite`、`typescript`、`vitest`。**不得引入任何 UI / 状态 / 工具库**。
5. `tsconfig.json` 开 `strict: true`、`noUncheckedIndexedAccess: true`、`moduleResolution: "bundler"`。
6. `public/data/events.json` 先放一个合法空种子（内容见下），T18 会替换为 2 条示例。

```json
{
  "schemaVersion": 1,
  "appVersion": "0.0.1",
  "savedAt": "2026-11-18T00:00:00+08:00",
  "categories": ["游戏发售","AI模型","硬件发布","软件工具","学术论文","影音作品","生活事件","其他"],
  "ui": { "sortOrder": "desc" },
  "events": []
}
```

## 严禁
- 不写任何 `.ts` 业务代码（`src/core/*`、`src/ui/*` 保持空目录）。
- 不配置 ESLint / Prettier / husky / CI。
- 不安装 `@types/node` 之外的类型包。

## 完成标准
- `npm install && npm run build` 成功产出 `dist/`，且 `dist/index.html` 里资源路径为相对路径。
- `npm run test` 能跑（0 个测试也算通过，报告不得报错）。
- `npm run typecheck` 无错误。
